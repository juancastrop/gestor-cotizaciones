# Gestor de Cotizaciones

Aplicacion web simple para generar cotizaciones de trabajos o servicios.

## Funciones

- Datos del cliente y de la cotizacion.
- Tabla de conceptos con cantidad y precio unitario.
- Calculo automatico de subtotal, descuento, IVA y total en CLP.
- Guardado local en el navegador.
- Generacion directa de PDF en una nueva pestaña del navegador.

## Como usar

1. Abre `index.html` en tu navegador.
2. Captura la informacion general y agrega items.
3. Pulsa **Guardar** para conservar la cotizacion en tu equipo.
4. Pulsa **Generar PDF** para abrir el documento en una nueva pestaña y descargarlo o imprimirlo.

## Nota

Este proyecto no necesita instalacion ni servidor para funcionar.
